## 📚 Progress Overview

### ✅ Day 1: Python Programming Basics
- **Variable and DataType.py**: Python introduction, variables, data types (string, integer, float, boolean, None), arithmetic operations
- **Expressions.py**: Operators (arithmetic, assignment, relational, logical), operator precedence, string operations
- **Input In Python.py**: User input handling (string, integer, float), conditional logic

### ✅ Day 2: Control Flow & Strings
- **Condition Statement.py**: if-elif-else statements, ternary operators, nested conditions
- **Indexing and String.py**: String indexing, slicing (positive/negative), string methods (endswith, capitalize, replace, find, count)
- **Type Conversion and Type Casting.py**: Type conversion, type casting, string concatenation

### ✅ Day 3: Data Structures
- **List and tuple.py**: Lists (mutable, methods: append, sort, reverse, insert, remove, pop), tuples (immutable, methods: index, count)
- **practice ques.py**: Practice problems on strings, conditions, lists, tuples (palindrome check, grading, movie lists)

### ✅ Day 4: Advanced Data Structures & Loops
- **Dict and set.py**: Dictionaries (key-value pairs, nested dicts, methods), sets (unique elements, methods: add, remove, union, intersection)
- **Loop Break and Continue.py**: While loops, for loops, break/continue statements, search algorithms
- **Range.py**: range() function, pass statement, factorial calculation
- **practice ques.py**: Dictionary/set practice (word meanings, classroom counting, marks storage)

### ✅ Day 5: Functions & File Operations
- **Function.py**: User-defined functions, parameters, return values (sum, table, average, factorial, currency conversion)
- **Recursion.py**: Recursive functions (factorial, natural numbers, list printing)
- **file.py**: File operations (read, write, readline, with statement), file searching, text processing

### ✅ Day 6: Object-Oriented Programming
- **Oops.py**: Classes, objects, __init__ constructor, creating instances
- **attributes.py**: Class vs instance attributes, methods, practical examples (student, team, account classes)
- **staticmethod.py**: Static methods, abstraction, encapsulation basics, account management (debit/credit)
